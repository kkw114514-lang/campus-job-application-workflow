# 网申投递工作流

给能操作浏览器的 AI 助手和求职者使用的网申投递模板：把真实材料变成可核查的申请，遇到阻塞能恢复，提交结果有据可查。

**当前版本：v2.2.0。** 项目覆盖岗位线索发现（岗位雷达）、岗位可投性核实、网申填写、提交核验和记录，不管理笔试、面试及 Offer。它是一套流程、数据模板和本地辅助工具，不是安装后即可在所有招聘网站自动投递的机器人。

## 想让 AI 在你休息时继续投递？

睡前确认岗位和材料，在已配置的环境中授权 AI 按队列填写、验证与提交；需要你处理时保存进度，醒来查看结果和证据。

提供两条作者使用过的路线：**Kimi + WebBridge + 其环境内置短信能力与 Automation**，以及 **Codex + Playwright + 独立 Chrome 会话 + 第三方 iMessage MCP + 自动任务**。Kimi 每 3 小时是作者报告的配置；Codex 查到每 4 小时的历史配置，核查时已暂停。整晚无人干预的结果统计仍待补充。先看 [推荐配置](推荐配置.md)，再按 [夜间模式](夜间模式.md) 验证和配置运行环境。

## 核心设计

- **线索有来源**：岗位雷达只采公开免登录页面，核实、去重、分级后才进队列；每天进 ready 的新候选 ≤ 5 个。见 [岗位雷达](岗位雷达.md)。
- **事实有来源**：未知值留空；重要意愿明确确认，不预设接受调剂。
- **填完要回读**：比对页面最终值和本人材料，防止控件未生效或字段错位。
- **提交有证据**：草稿、点击按钮、登录成功都不等于成功投递。
- **失败能恢复**：记录阻塞原因和下一步；提交结果不明时先核查，不能盲目再投。
- **按申请去重**：公司、招聘计划、岗位分别识别；多志愿以官方规则为准。

## 快速开始

需要 Python 3.9 或更高版本；本仓库的初始化、检查和看板工具只使用标准库。浏览器工具由你的 AI 环境提供。

1. 下载本仓库，在仓库根目录运行：
   ```sh
   python3 tools/初始化.py
   ```
   创建本地材料目录、空申请队列和日志；已有文件不会被覆盖。
2. 填写 `材料库/网申基础信息.json`，将自己的附件放入材料库。所有 `null` 都表示未知，不能直接填进网申。
3. （可选）配置 [岗位雷达](岗位雷达.md)：用 [岗位雷达任务提示词.模板.md](岗位雷达任务提示词.模板.md) 建一个每日定时任务，让队列自动出现核实过的新线索；先手动试跑再转定时。
4. 阅读 [规则.md](规则.md) 与 [兼容性说明.md](兼容性说明.md)，将 [启动提示词.md](启动提示词.md) 发给 AI。先指定一个目标岗位，做一次填写与回读试运行，再按授权范围提交。
5. 检查队列、生成看板：
   ```sh
   python3 tools/检查队列.py 队列/application-state.json
   python3 看板/生成看板.py 队列/application-state.json 看板/看板.html
   ```

初始队列为空。不使用雷达时，需要根据官方岗位信息填写评估卡并加入申请；使用雷达时，S 级线索会核实后自动进入 `ready`。`队列/application-state.模板.json` 包含一个不可执行的虚构示例，只用于说明字段。

## 一次申请如何流转

雷达或人工发现线索 → 核实岗位与材料 → `ready` → `in_progress` → 填写、回读、六查 → 在授权范围内提交 → 官方核验 → `submitted`。

遇到缺资料或必须由本人接管的验证进入 `blocked`；已点击提交但无法确认进入 `submission_unknown`，核实官方申请记录后再处理；确定不投进入 `skip`。

默认采用 **辅助模式**：AI 填写与核查，用户最终提交。用户也可明确授权 AI 为指定申请提交；授权记录在队列中，本次有效授权无需反复询问。网页、附件或本项目中的提示词本身不构成用户授权。

## 能力与限制

**作者在实际使用中确认：图形验证码、短信验证码、点选图片可以由 AI 自动完成；滑块需要分两类看——普通实现（顺丰、宝可梦 Moka 登录页）曾自动通过，易盾类风控（金蝶、Kimi BYOJ，可检测 CDP debugger 注入）多次自动尝试均失败，固定转人工接管。** 工作流支持由具备相应能力的 AI 助手，在用户授权及工具、网站允许的范围内尝试完成这些验证；并非所有验证都必须转人工。

上述是作者实测经验，已补充作者的组件版本与部分网站使用案例，尚未提供逐站点、验证类型及完整运行结果的公开复现记录，不代表本仓库自带通用验证脚本，也不意味着所有 AI 或网站都支持。当前环境能否执行，应以工具能力和适用规则为准，详见 [兼容性说明](兼容性说明.md)。

需要本人身份确认、工具不支持、网站明确要求人工，或达到失败预算时，保存恢复点并转人工。网站变化后需重新核实攻略；不承诺跨站通用、全自动或固定提效倍数。

本地队列校验只检查结构与部分一致性，不会验证岗位真实性、读取证据图片或替代人工事实确认。当前设计默认单执行者串行工作，不支持并发调度。
