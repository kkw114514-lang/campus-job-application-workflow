# 投递状态共享（人机/多AI协作防重复协议）

> 任何 AI 或个人每完成/尝试一次投递动作，立即在此追加一条。提交前必须 `grep 公司名` 查本文件。

## 记录格式（每行一条，倒序最新在上）

```
[日期 时间] 公司 | 岗位全名 | 渠道(官网/邮箱/内推/LinkedIn) | 结果(submitted/blocked/失败原因) | 操作者(AI名/本人) | 证据路径或说明
```

## 规则

- **submitted** 仅限：官方页面/邮件明确成功 + 岗位名一致 + 证据截图已存。
- 官网草稿、登录成功、填表完成一律不算，记 `blocked(草稿)` 或过程描述。
- 同一公司多渠道投递禁令（如官方规则"仅一个渠道"）在此注明出处。
- 志愿额度使用情况在此登记（例：已用 2/2 志愿，截止前可改 N 次）。

## 记录区（最新在上）

```
[20XX-XX-XX] 示例公司 | 示例岗位 | 官网 | blocked(滑块验证码3次失败) | 说明：恢复条件=用户人工登录后AI接手
```
